# 🎓 SENAC QUIZ

Projeto desenvolvido para consolidar conhecimentos em back-end com PHP e integração com banco de dados.

O **SENAC QUIZ** é uma aplicação web com sistema de autenticação, perguntas e respostas, cálculo automático de pontuação e armazenamento em banco de dados.

---

## 📌 Funcionalidades

- ✅ Sistema de Login
- ✅ Controle de sessão de usuário
- ✅ Quiz com perguntas e respostas
- ✅ Cálculo automático de pontuação
- ✅ Armazenamento da pontuação no banco de dados
- ⚠️ Ranking fictício (simulação visual)

---

## 🛠 Tecnologias Utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP (ambiente local)

---

## ⚙️ Como rodar o projeto localmente

### 🔧 Pré-requisitos

- XAMPP ou WAMP instalado
- PHP 7+
- MySQL
- Navegador atualizado

### 🚀 Passo a passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/seuusuario/senac-quiz.git

Mova a pasta do projeto para:

C:/xampp/htdocs/

Inicie o Apache e o MySQL pelo XAMPP.

Acesse o phpMyAdmin e crie um banco de dados.

Importe o arquivo .sql que está na pasta do projeto.

Acesse no navegador:

http://localhost/Senac-quiz
